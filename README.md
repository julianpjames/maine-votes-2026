# Maine Votes 2026

An independent, nonpartisan guide to Maine's 2026 elections.

## Website

The static site is served from `index.html` in the repository root. The companion datasets are `local_elections.csv` and `finance_source_registry.csv`.

## Publishing

Connect this repository to Cloudflare Pages using Git integration, with production branch `main`, no framework preset, no build command, and output directory `/` (repository root). Subsequent commits to `main` deploy automatically.

## Editorial standards

Official election and campaign-finance sources take precedence. Include citations and reporting periods. Separate verified facts, campaign claims, outside spending, and analysis. Review interpretive political claims before publication.
